# MyPlayer
A simple ANDROID APP that can PLAY LOCAL MEDIA FILES and STREAMING URL supported by Streamlink (https://github.com/streamlink/streamlink) and yt-dlp (https://github.com/yt-dlp/yt-dlp) smoothly so my other app Live Subtitle V1 (https://github.com/botbahlul/Live-Subtitle) and Live Subtitle V2 (https://github.com/botbahlul/Live-Subtitle-V2) can do the Speech Recognition without any audio/video interruption.

All this long I've been looking for a player which can play continously when I run my Live Subtitle app whithout any luck.

Couple years ago I found that VLC is the one which suite my need, but sadly it can not play youtube streaming anymore.

That's why I decide to make my own media player.

Please note that some youtube channels now need you to login to play that streaming, so that's why when you paste that kind of URL this app will ask you to import a "youtube_cookies.txt" file.

To get that "youtube_cookies.txt" file you will need Kiwi Browser (https://github.com/kiwibrowser/src.next/releases) or other browsers that support installing browser extension.

Install the Get cookies.txt LOCALLY extension (https://chromewebstore.google.com/detail/get-cookiestxt-locally/cclelndahbckbenkjhflpdbgdldlbecc) into Kiwi Browser, login into your youtube account, and then when still in youtube site,  using that extension, export youtube cookie in Netscape cookies.txt format with "youtube_cookies.txt" as saved filename.

After that now you can select that file when the Import Youtube Cookies dialogue shown up.

IMPORTANT NOTES!

Do not share that cookie file! It contains sensitive session information that may allow access to your account!
